## Featured project — CollegeKhoj

**CollegeKhoj** is a college-discovery web application. I used it as a hands-on DevOps learning project: a frontend and backend are containerized, supported by MySQL, deployed to AWS, and built through Jenkins.

| Area | Hands-on work |
